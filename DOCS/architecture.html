NeuroMech-Warn architecture

A causal, neuroscience-guided electrode-graph model with a neural-mass digital twin, a time-to-seizure forecaster and a cascaded alarm, built to warn earlier than prior work on unseen TUSZ patients.

Dataset: TUH EEG Seizure Corpus (TUSZ)9 components · 5 heads · 8 novel contributionsFile: DOCS/ARCHITECTURE.md

"Earlier and better than previous work" is the design goal. Only experiments on TUSZ can prove it, so the design includes an ablation plan that shows which part produces each gain.

Built on the literature

Three base approaches, plus supporting ideas

Base #1 · when to alarm

Soft-label onset + evidence accumulation

Xu 2024, Expert Syst. Appl. 2.3 s latency, but patient-specific and never tested on TUSZ.

Base #2 · where and what

Electrode-graph spatiotemporal encoder

Tang 2022 (ICLR) and Craley 2022 (PLoS ONE, SZTrack). Per-electrode outputs give spread and onset zone; graph pooling gives type.

Base #3 · why the brain changes

Brain-dynamics early-warning features

Duma 2025 (BMC Med.) and Maturana 2020 (Nat. Commun.). 1/f exponent, critical slowing and connectivity change minutes before onset.

Supporting: Jemal 2024 (domain adaptation), Meng 2025 (k-of-n alarm), Zabihi 2026 (alarm-budget protocol), Karoly 2018 and Sun 2024 (neural-mass modelling), Jeppesen 2025 (ECG), Liu 2026 (small models are enough).

Component 2 · neuroscience core

Neural-mass digital twin new

OFFLINE:  Wendling model (pyramidal + excitatory + slow & fast inhibitory interneurons)
          → simulate ~200k signals over a wide range of A, B, G, a, b, g
          → train an amortized neural posterior estimator (sbi library)
            input : spectrum + 1/f + stats of one channel-window
            output: probability distribution over A, B, G, a, b, g

ONLINE:   every slow window, every channel → posterior in milliseconds
          → E/I indicators A/(B+G), A/G, uncertainty width → "physiology tokens"
          → drives the virtual-neuron simulation in the dashboard
  • Turns EEG into interpretable brain parameters (Wendling 2002, Karoly 2018).
  • Amortized: trained once, instant per window, so it runs live (SBI, DeepSIF idea).
  • Direction-agnostic: learns whether E/I rises or falls before seizures. Duma found a shift toward inhibition.
  • Keeps the uncertainty as a signal of its own.
Component 3 · learned model

Electrode-graph encoder

Fast window per electrode (4 s)
 → SHARED temporal CNN (EEGNet-style: frequency filters → features)    [SZTrack, Jemal]
 → node embedding h_i(t) for each of 22 electrodes
 → DYNAMIC GRAPH: edges = learned + electrode distance + LIVE wPLI       [new]
 → 2 graph-attention layers                                               [Tang]
 → CAUSAL temporal model per node: selective state-space (Mamba-style) or GRU
 → per-node states + attention-pooled global state
  • Per-electrode outputs give the spread map and onset zone, and work with fewer channels.
  • The graph rewires as synchrony rises, so the graph itself becomes a warning signal.
  • Target size 1–3M parameters, within reach of a single GPU.
Component 4 · learned model

Neuro-guided fusion

  • Cross-attention: each electrode's embedding attends to its own and its neighbours' brain-state and physiology tokens.
  • Gating: learned trust between neuroscience and learned features, for example trusting 1/f more under artifact.
  • Patient-baseline normalization new: features also expressed against the patient's first calm minutes in the session.
  • Domain-adversarial training (DANN, Jemal 2024) so features do not encode patient identity.

Xu's soft-label idea, extended from seconds to minutes. Risk is taught to build up, which gives earlier and smoother warnings than an arbitrary preictal cut-off.

Component 6 · where "earlier" is decided

Cascaded alarm engine

Stage A · FORECAST ALARM
  hazard H1 → log-likelihood ratio → CUSUM accumulator (quickest change detection)
  + k-of-n confirmation + 30-min refractory period                         [Meng]
  → "⚠ Seizure likely in ~X min" + reasons

Stage B · ONSET ALARM
  onset prob H2 → accumulated rising evidence → alarm                       [Xu]
  CASCADE: if Stage A is active, Stage B's threshold is LOWERED (prior boost)  [new]

Calibration: thresholds tuned on TUSZ dev under an explicit false-alarm budget,
             then frozen                                                     [Zabihi]
             conformal risk control guarantees the budget                    [new]

The forecast stage buys minutes of warning. Its prior boost buys seconds at onset.

Components 7 – 8 · outputs and deployment
  • Explainer: contribution per feature group (1/f, slowing, connectivity, E/I parameters, learned graph) plus graph-attention maps.
  • Report: template-based, as in README section 4.3.
  • Dashboard: scalp topomap (MNE), 3D brain sources (fsaverage + eLORETA), live network graph, virtual neurons driven by the inferred A/B/G, risk timeline.
  • Tiny model: distilled 4-channel behind-the-ear student, under 100k parameters, int8, with MFLOPs per second reported.

Proof, one part at a time

Ablation plan

Remove one component at a time and measure warning time, onset latency, sensitivity and false alarms:

  1. No neuro-dynamics bank
  2. No digital twin
  3. Static graph instead of dynamic graph
  4. Hard labels instead of soft ramps
  5. Binary head instead of hazard head
  6. No cascade
  7. No patient-baseline normalization
Known risks

What could limit the results

  • Short TUSZ sessions cap the hazard head at about 30 min, and many seizures have little preictal data. Check the data first.
  • Per-electrode spread labels depend on TUSZ v2 channel annotations, which need verifying.
  • ECG is missing in some recordings, so the body module must work without it.
  • The digital twin is the riskiest scientific bet. If E/I parameters add nothing, that is reported as a finding.
  • Scope is large. Build order: 0 → 3 → 1 → H2/H1 → alarm → 2 → H3–H5 → dashboard → tiny model.
