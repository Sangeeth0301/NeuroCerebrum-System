NeuroMech-Warn architecture

Graph Neural-Mass Dynamics: a causal model whose hidden state is a network of excitatory and inhibitory neural populations, built to forecast when, where and what type of seizure is coming on unseen TUSZ patients.

Dataset: TUH EEG Seizure Corpus (TUSZ) · external: CHB-MIT, Siena9 components · 5 heads · 8 novel contributionsFile: DOCS/ARCHITECTURE.md

Thesis: a graph neural-mass model that forecasts when, where and what type of seizure is coming, and explains the warning through the brain's own loss of stability.

"Earlier and better than previous work" is the design goal. Only experiments on TUSZ can prove it, so the design keeps a strong fallback backbone and an ablation plan that shows which part produces each gain.

Components 0 – 2 and 4

Inputs, neuroscience and fusion

Component 0 · front-end

Causal front-end

  • Montage: TUSZ → 22-channel TCP bipolar at 250 Hz, handling AR1, LE2, AR3, LE4 references (MLSPred-Bench code).
  • Causal filters: IIR 60 Hz notch + 0.5–45 Hz, forward-only.
  • Artifact gate: small CNN trained on TUAR flags eye, muscle and electrode artifacts per channel and down-weights them.
  • Two clocks: SLOW 60-s windows every 10 s over the last 30 min; FAST 4-s windows every 1 s.
  • ECG path: R-peaks → heart rate, HRV (minutes) and tachycardia onset (seconds), when the channel exists.
Component 1 · neuroscience

Neuro-dynamics bank

Per channel, causal, kept as trajectories: aperiodic 1/f exponent + offset (specparam), band powers, critical slowing (variance, lag-1 autocorrelation, decay), interictal spike rate, line length / Hjorth / entropy, and wPLI/PLV with directed in/out flow. Slow wPLI serves forecasting, fast 4-s wPLI serves onset; both set the backbone's coupling Wij.

Component 2 · neuroscience

SBI twin: prior for the gains

Offline Wendling simulations train an amortized posterior estimator. Online, every channel and slow window gets a posterior over A, B, G (time constants fixed first), used as the prior for the backbone's gains. Checked with simulation-based calibration and posterior-predictive checks.

Component 4 · learned

Neuro-guided fusion

  • Gated cross-attention between each electrode's state and its own and neighbours' brain-state tokens.
  • ECG tokens with missing-modality dropout, since TUSZ has ECG in only some files.
  • Running robust patient baseline from artifact-free, low-risk windows; population baseline at session start.
  • Domain-adversarial training so features do not encode patient identity.
Component 3 · core novelty

Graph Neural-Mass ODE backbone

Each electrode i: latent E/I population  x_i = [pyramidal, excitatory, slow-inhibitory, fast-inhibitory]

   dx_i/dt =  Wendling_f( x_i ; A_i(t), B_i(t), G_i(t) )     ← mechanistic E/I dynamics
            + Σ_j  W_ij(t) · S(x_j)                           ← graph coupling = spread
            + NN_residual( x_i, context )                     ← learned correction

   A_i, B_i, G_i (t) : slowly drifting gains, updated every slow window (SBI prior)
   W_ij(t)           : dynamic coupling = live wPLI + electrode distance + learned
   EEG_i ≈ observation(x_i)  → reconstruction loss keeps the latent physiological
  • The hidden state is a population of excitatory and inhibitory neurons, so the dashboard's virtual neurons are the model itself.
  • Runs on a ~50 Hz latent with a fixed-step solver and short roll-outs to stay trainable.
  • Differs from published physics-informed seizure models, which use Kuramoto phase oscillators without E/I physiology.
  • Fallback: shared temporal CNN → dynamic graph attention → causal state-space model, kept for ablation and as a guaranteed baseline.

Components 6 – 8

Cascaded alarm and outputs

Stage A · FORECAST   hazard (H1) + stability margin (H2) + HRV trend
                     → log-likelihood ratio → CUSUM → k-of-n + 30-min refractory
                     → "⚠ focal seizure likely in ~X min, left temporal"

Stage B · ONSET      onset prob (H3) + tachycardia onset → accumulated evidence → alarm
                     while A is active: threshold lowered by a BOUNDED amount (≤ 20%)

Calibration          per-type thresholds; whole cascade calibrated to ONE false-alarm budget
                     dev split by patient: half for thresholds, half for conformal calibration
Outputs
  • Explainer: contributions of feature groups, gains and stability; graph-attention maps.
  • Report: auto seizure report as in README section 4.3.
  • Dashboard: scalp map, 3D brain (fsaverage + eLORETA), live network, virtual neurons from the model state, spread preview from the roll-forward, risk timeline.
  • Distilled student: 4 channels, under 100k parameters, int8, MFLOPs reported.
